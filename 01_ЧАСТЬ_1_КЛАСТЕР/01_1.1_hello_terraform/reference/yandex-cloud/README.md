# Reference: provider Yandex Cloud и одна VM

Это короткий reference-фрагмент для доски и суфлёра. Он показывает ту же пару
понятий `provider` + `resource` на реальном облачном API, но не используется
для создания рабочего пяти-VM стенда.

Рабочий стенд находится в `04_1.3_five_vm_terraform/terraform/` и разделён на
root module и переиспользуемые модули.
